# terraform-aws-networking-tf-course-practice
Networking module created during terraform practice.

This module manages the creation of a VPC with subnets, allowing for the creation of both public and private subnets.

Example usage:
```
module "vpc" {
  source = "./modules/networking"

  vpc_config = {
    cidr_block = "10.0.0.0/16"
    name       = "your_vpc"
  }

  subnet_config = {
    subnet_1 = {
      cidr_block = "10.0.0.0/24"
      az         = "us-east-1a"
    }
    subnet_2 = {
      cidr_block = "10.0.1.0/24"
      public     = true
      az         = "us-east-1b"
    }
  }
}
```
